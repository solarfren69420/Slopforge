THE SLOPFORGE WAY

Follow the source.
Keep the possibilities open.

Slopforge helps you discover community game engines, source ports, original open-source games, creative software, and compatibility tools. Every card links to its upstream GitHub repository or project hub.

Bring your own data

Some game engines require files from a legally obtained original game. Read the project’s setup instructions. Slopforge hosts no ROMs, game assets, proprietary binaries, cracks, or license bypasses.

Labels mean something

Game reimplementations, application rewrites, source ports, and independent creative tools have separate labels. “Clean-room rewrite” attributes the upstream maintainer’s methodology claim; it is not a completed feature-parity or independent provenance audit. Source-available tools have custom license terms, shown in their details. A listing is not a build verification, completion score, or endorsement by the original rights holder.

Your library stays with you

Saved projects live in this browser’s local storage. There are no accounts or tracking scripts. GitHub Pages operates the hosting.
