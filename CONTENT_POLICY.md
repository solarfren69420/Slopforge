# Slopforge content policy

Slopforge is a directory of community software projects. The public site contains original website code and artwork, project descriptions, category and method labels, and upstream repository links.

## Accepted listings

Community game reimplementations, source ports, independently developed open-source games, game engines, creative and professional open-source software, compatibility layers, and legitimate code analysis tools may be submitted with upstream evidence. A listing must accurately identify the maintainer and the project's purpose, source location, and data requirements.

## Content we do not host or accept

- ROMs, disc images, proprietary game data, copyrighted asset packs, original commercial executables, or keys.
- Leaked proprietary source, cracked installers, activation bypasses, DRM circumvention instructions, or links promoted as piracy sources.
- Misleading listings that label independent alternatives as decompilations of commercial products.
- Fabricated progress scores, star counts, compatibility claims, or endorsements.

Linking to an upstream engine does not grant rights to any game data. Use legally obtained files and follow the upstream licenses and installation instructions. Some projects document freely licensed replacements or authorized shareware; those requirements are recorded rather than bundled here.

## Names, art, and attribution

Names identify their respective projects and products. Slopforge is an independent directory. Its original forge illustration and symbolic cards are branding, not upstream screenshots or claims about a project's appearance. We do not reproduce commercial logos, UI screenshots, or game assets in catalog cards.

Upstream projects and their files retain their own licenses. The website's MIT license applies to Slopforge's original website code and metadata, not linked software, third-party marks, or game data. See [ARTWORK.md](ARTWORK.md) for artwork provenance.

## Review and corrections

Contributors must provide a maintainer-controlled source describing the project and its requirements. Maintainers review submissions before merging. A reachable repository, an open-source label, or a listing is not a legal clearance or build certification.

Report inaccurate metadata, unsuitable links, or rights concerns through the [correction form](https://github.com/solarfren69420/Slopforge/issues/new?template=correction.yml). Identify the listing and evidence; do not attach proprietary files. Maintainers can correct or remove listings after review.

## Privacy

Favorites are stored only in this browser's local storage under `slopforge-library`. Slopforge has no accounts, analytics scripts, or external font requests. GitHub Pages provides hosting and may process requests under its own policies. Opening an upstream link visits that external project. Clearing browser storage removes your saved library.
